# 🎙️ Assisto.AI — AI-Powered Voice Assistant & Autonomous Agent

**Assisto.AI** is an intelligent, voice-driven AI customer support and navigation agent. Built to seamlessly integrate into any modern web application, Assisto.AI listens to user speech, processes business data using the Google Gemini API, speaks real-time answers, and can even automatically drive page navigation on the host website.

Whether deployed as an interactive widget or a standalone voice agent, Assisto.AI transforms standard web browsing into a hands-free conversational experience.

---

## 🔥 Key Features

* 🗣️ **Conversational AI Voice:** Real-time speech-to-text input paired with high-quality text-to-speech voice responses.
* 🧩 **Embed Anywhere Widget:** Simple script integration allows Assisto.AI to be embedded into any external website in minutes.
* 🧭 **Autonomous Page Navigation:** Users can navigate between website pages simply by asking the AI assistant.
* 🧠 **Custom Business Knowledge Base:** Learns and references business context to answer customer support FAQs accurately.
* ⚡ **Instant Real-Time Responses:** Low-latency response generation powered by Gemini APIs.
* 🔐 **Secure Backend Infrastructure:** Full MERN stack architecture with user session handling and route security.
* 🎨 **Modern Responsive UI:** Polished interface crafted with Tailwind CSS for fluid user interaction across all device sizes.

---

## 🛠️ Tech Stack

### **Frontend**
* ⚛️ **React.js** — Component architecture & UI rendering
* 🎨 **Tailwind CSS** — Modern utility-first styling
* 🎤 **Web Speech API** — Browser-native Speech Recognition & Speech Synthesis

### **Backend & Intelligence**
* 🟢 **Node.js & Express.js** — High-performance RESTful API services
* 🍃 **MongoDB** — NoSQL database for managing knowledge base, chat histories, and agent settings
* ♊ **Google Gemini API** — Core AI engine powering intent extraction and contextual generation
